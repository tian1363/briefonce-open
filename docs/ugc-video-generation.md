# 视频生成使用说明

更新日期：2026-10-15。

在创作输入框说明目标，选择产品和参考素材，再核对脚本、提示词、型号、比例及视频时长后提交。任务状态、结果预览与下载从历史记录查看。

当前接口目录包含 Seedance 2.0、Seedance 2.0 Mini、MiniMax H3、MiniMax H3 Max；实际可选项取决于部署配置和服务权限。时长范围为 4–15 秒，比例和参考方式以当前型号选项为准，不支持的组合会在提交前拒绝。

未启用的组合不能提交。接口接入与供应商实际出片是不同的验证环节；测试服务不能替代真实出片验收。失败或状态不明确时保存任务编号，先核对历史状态，不重复提交相同付费任务。

已完成视频保留在历史记录，文件下载需登录并属于当前账号。视频与商品事实需人工核对后再发布。
