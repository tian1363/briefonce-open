# BriefOnce 技术设计概览

更新日期：2026-10-15。本页描述当前公开版本的主要结构，接口事实以 `internal/web/routes.go` 为准。

## 结构

- Go 服务：认证、数据访问、素材处理、任务执行、模型调用与静态文件。
- React 前端：创作、产品资料、创意空间、工具与工作流和历史。
- SQLite：账号、产品、素材关联、对话、任务、调用与行为记录。
- 本地文件存储：用户上传和生成产物；文件读取需验证账号归属。

## 创作与任务

产品资料提供事实背景。对话与专用工具各有明确入口，模型按文字、多模态、图片、视频等能力配置。异步生成任务保存状态和必要的关联标识，结果持久化后再供用户预览与下载。

图片工作流为模特姿势、挂拍图精修和商品详情长图。商品图、人物图、姿势图与版式参考有独立职责。每个姿势对应一个输出；参考商品图数量不放大输出数量。

详情图由模型结合实际参考图片和商品事实生成，可选择整页或逐屏；下载适配不重新绘制商品内容。视频使用当前启用的视频模型目录，前后端均检查参数组合。

## 安全与隔离

会话由服务端验证。资源查询和文件读取都验证账号归属；用户密钥加密存储，前端只取得必要状态。数据库、上传目录和真实环境文件不进入 Git。


## 运行

当前部署使用单实例和持久化目录。FFmpeg 用于视频探测及素材处理。模型供应商由服务端访问，不向浏览器返回凭证。部署和备份见[部署说明](managed-deployment.md)。
