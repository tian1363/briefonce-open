# 从参考视频提取素材，再继续创作

适合把零散的视频参考整理成后续可用的产品素材。

1. 进入“视频素材提取”，上传参考视频或提供支持的来源。
2. 查看解析成功的资产，放大预览图片，并展开需要核对的描述。
3. 把适合的资产导入产品资料，作为后续任务的上下文。
4. 在创意解读中理解参考内容，或在对话里继续写开头、脚本和分镜。

例如可以提出：“结合当前产品资料，参考这段视频的开头节奏，设计三个适合我的商品的原创开头。”

本地视频提取需要 FFmpeg 和 ffprobe。对于外部页面，只使用实际解析到的内容；需要登录的图文来源还依赖浏览器连接与页面可访问状态。
