# BriefOnce 官网表达

## 品牌与语气

BriefOnce 面向品牌、电商和内容创作者，表达应简短、直观、亲近用户。主张为“产品讲一次，广告持续做。”已确认的产品资料可以复用，新的创作要求仍需补充。

## 当前可展示能力

- 视频素材提取、创意解读。
- 模特姿势、挂拍图精修、商品详情长图三个工作流。
- 产品资料与历史作品。

优先以实际图片或清楚标注的视觉示意展示使用路径。图标使用统一风格，含义不明确时保留短标签和可访问名称。

## 发布边界

公开介绍不包含内部运营手段、商业定价资料、账号凭证或管理截图。只展示当前用户可见的入口，不以旧实现或历史方案补充功能清单。
