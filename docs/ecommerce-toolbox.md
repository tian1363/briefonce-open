# 工具箱与工作流

更新日期：2026-10-15。

## 入口

工具箱包含两个工具：视频素材提取、创意解读。工作流分为模特姿势、挂拍图精修、商品详情长图。创作首页保留相同的工具和场景名称。

## 画布

场景栏位于画布上方，产品资料与作品库位于右侧。首次进入适配完整节点；手动缩放、拖动和重置视图不会删除作品。节点使用自有选择组件，商品选项展示封面，长名称不撑宽节点。

姿势库通过独立弹窗选择，节点只展示已选姿势。详情页参考库位于视觉参考节点，必须展示实际图片；选中参考图后传给模型。

## 任务与结果

多张商品图共同约束一个商品，每个姿势对应一个输出。图片任务逐张保存状态与结果；详情页由 AI 策划后生成整页或分屏。作品保存在服务端，可预览、下载和复用。

提取成功的资产集中展示，可批量导入产品资料；资产描述保存简洁内容，不保存判定过程。产品附件支持放大预览、替换和移除，移除关联不删除作品库历史。

详细步骤见[产品手册](product-user-manual.md)。
