# 自托管部署说明

更新日期：2026-10-15。本页只说明可公开的运行与部署配置。

## 准备环境

需要 Go、Node.js 与 npm；视频素材抽帧需要 FFmpeg 和 ffprobe。版本要求及构建命令见[README](../README.md)。使用 SQLite 与本地上传目录，单个数据库只运行一个应用实例。

## 配置与启动

1. 按 `.env.example` 配置监听地址、数据目录和上传目录。真实配置文件不提交 Git。
2. 为 `SCRIPT_AGENT_ENCRYPTION_KEY` 生成独立密钥，妥善保存，不能在已有数据后随意更换。
3. 配置所需模型服务，使用与接口和地域匹配的凭证。不要将凭证放入图片、截图、示例文件或浏览器代码。
4. 构建前端并启动 Go 服务；也可以使用仓库提供的 Compose 配置。
5. 公网部署启用 HTTPS、安全 Cookie 和合适的注册限制。具体访问地址由部署者提供。

首次注册不自动获得管理权限。权限初始化和账号隔离规则见[邀请测试部署](invite-deployment.md)。

## 持久化与备份

数据库和上传目录需要持久化并一起备份，加密主密钥单独备份。发布前制作一致性快照，并在独立环境验证恢复。健康检查为 `GET /api/health`。

保留已有数据目录，不将运行数据库、日志、用户素材或部署凭证提交到公开仓库。业务运营与商业配置不属于公开部署资料。
