# 模特姿势与商品详情图

核对日期：2026-10-15。入口为“工具箱 → 工作流”。

## 模特姿势

选择同一商品的参考图片、模特和姿势。姿势库在独立弹窗中展示图片与筛选；每个选中姿势生成一张图，多张商品图不参与排列组合。

生成请求同时传入动作描述和所选姿势图，姿势图只参考身体动作。人物身份来自模特参考，商品外观来自商品图。缺失视角和不可见结构需要对照实物核验。

## 挂拍图精修

依据原始商品图生成白底展示或可见细节特写，核对颜色、纹理和结构。结果可从作品库继续用于详情页。

## 商品详情长图

选择商品素材并核对事实，按服装、鞋履品类、卖点及平台查看参考图。实际参考图片随请求传给模型，用于版式、构图和配色；商品信息以已确认资料为准。支持整页生成或逐屏生成，结果供预览与下载。

资源图用于参考，不代表取得商业使用许可；公开发布前检查商品事实、文字、商标和外观。详细操作见[产品手册](product-user-manual.md)。
