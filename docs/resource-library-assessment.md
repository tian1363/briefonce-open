## 已落实

- 修复创作画布只显示前十个姿势的问题，已有男装动作现在可见。
- 现有 13 个动作保留原编号和预览；增加 8 个原创文字动作，共 21 个。新增动作无图片时直接展示动作说明，避免破图和错误预览。

- 姿势仍通过现有服务端预设校验和批量任务生成；不改变计费与原图输入职责。

## 下一步优先级与验收

1. 自有姿势预览：先为新增的八个动作制作并审核示例图；画面与动作一致，清楚标为示例，商品图仍是商品事实依据。
2. 自有模特配对：先扩展少量高频风格，而非一次生成 162 位。每位保存近景、全身、风格、生成记录与人工审核状态；换装前验证人物一致性。
3. 详情页服装适配：先制作衬衫、牛仔裤、运动服三种原创布局；复用现有商品事实、平台导出与逐屏出图功能。每种须验证长短文案、空字段和真实商品图，避免只有模板名称没有布局差异。
4. 后续增加资源管理时分别记录文件可用状态、来源证据、使用范围与人工审核结果；只有实际可读取并获准使用的文件进入可选图片库。来源信息与生产可用性分开保存。

以上后三项是后续计划，本次没有生成模特原图或实现 34 套详情模板。
